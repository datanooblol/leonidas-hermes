1. คัดกรองลูกค้า
อายุ

อาชีพ

โรคประจำตัว / ประวัติการรักษา

เหตุผล: ถ้าลูกค้าไม่เข้าเกณฑ์ ประกันออกไม่ได้ → ไม่ต้องไปถามขั้นตอนอื่นให้เสียเวลา

2. ความกังวลหรือความต้องการ
เวลานึกถึงเรื่อง “ความคุ้มครอง” ลูกค้ากังวลเรื่องไหนมากที่สุดคะ/ครับ?
➜ สุขภาพ / อุบัติเหตุ / ดูแลครอบครัว / ภาระการเงิน / ค่ารักษาพยาบาล ฯลฯ

เหตุผล: เปิดพื้นที่ให้ลูกค้าเลือกหมวดที่เขาต้องการ แล้วเราจึงชี้ไปยังประกันที่ตรงกับคำตอบนั้น

3. คำถามค้นหาวัตถุประสงค์ (Purpose-based)

คำถามเพิ่มเติม:

ถ้ามีเหตุไม่คาดคิด ลูกค้าห่วงเรื่องอะไรเป็นอันดับแรกคะ/ครับ?
➜ รายได้หาย? ค่ารักษาแพง? ภาระลูก/ครอบครัว?

คำถามนี้ช่วยให้รู้ว่าเขาต้องการประกันประเภทไหนโดยไม่ต้องถามตรงๆ

4. ใช้คำถามสำรวจ “ประกันที่มีอยู่”

กว้างกว่าเดิม:

ตอนนี้มีประกันประเภทไหนอยู่บ้างคะ/ครับ? (เช่น สุขภาพ ชีวิต หรืออุบัติเหตุ)

มีอะไรที่รู้สึกว่ายังไม่ครอบคลุมหรืออยากเพิ่มความคุ้มครองไหมคะ/ครับ?

ลูกค้าจะเผยช่องว่าง (gap) → เราใช้ gap นั้นเป็นตัวกำหนดแบบประกันที่ควรเสนอ

5. ปรับงบประมาณให้เป็นกลาง ไม่ผูกกับประเภท

ถามแบบนี้:

ตั้งงบค่าความคุ้มครองไว้ประมาณเท่าไหร่ต่อเดือนคะ/ครับ?

อยากได้แบบเบี้ยไม่แพง หรืออยากได้ความคุ้มครองสูงสุดคะ/ครับ?

ไม่ต้องแบ่งตามประกันประเภท ให้ใช้คำกลางๆ เช่น “ความคุ้มครอง”

6. คำถามปิดการขายให้เป็น “ทางเลือกตามความต้องการลูกค้า”

แทนที่จะถามว่า “สนใจประกันสุขภาพไหม” → ให้ใช้แบบนี้:

ถามแบบเปิดทางเลือก:

จากที่คุยกัน คิดว่าความคุ้มครองแบบไหนน่าสนใจที่สุดสำหรับลูกค้าคะ/ครับ?
➜ ครอบคลุมค่ารักษา, คุ้มครองอุบัติเหตุ, หรือคุ้มครองชีวิตให้ครอบครัว

ทำให้ลูกค้าเลือกเองว่าเขาแคร์เรื่องไหน
